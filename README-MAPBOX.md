# Mapbox Streets v12 для Taxi Dashboard

Изолированная реализация DXH-TAXI-MAPBOX-01 / STAGE-A. Leaflet остаётся 1.9.4,
бэкенд и GPS-алгоритмы не изменялись. В production ничего не внедрялось.

## Как работает карта

1. Карта создаётся сразу, базовым слоем ставится OSM (карта не бывает пустой).
2. Приложение пытается прочитать публичный токен:
   - `window.MAPBOX_ACCESS_TOKEN` (для тестов/отладки), затем
   - `static/mapbox-token.json` (штатная конфигурация).
3. Токен принимается только формата `pk.*`; `sk.*` и укороченные значения
   отбрасываются.
4. Выполняется проверка одного тайла Mapbox. При успехе OSM-слой заменяется
   на Mapbox без перезагрузки страницы; маршрут, GPS-точки и масштаб остаются.
5. Если токена нет, он неверный, Mapbox недоступен или тайлы три раза подряд
   вернули ошибку — остаётся/возвращается OSM-слой. При ошибках тайлов
   показывается уведомление «Mapbox недоступен — карта переключена на
   OpenStreetMap».

Параметры Mapbox:

- style: `mapbox/streets-v12`
- URL: `https://api.mapbox.com/styles/v1/mapbox/streets-v12/tiles/512/{z}/{x}/{y}{r}?access_token={accessToken}`
- `tileSize: 512`
- `zoomOffset: -1`
- `maxZoom: 19` (как у прежнего OSM-слоя)
- атрибуция: Mapbox, OpenStreetMap contributors, ссылка Improve this map.

## Настройка публичного токена

Нужен **публичный** токен Mapbox (`pk.*`). Секретный `sk.*` использовать
нельзя: он не должен попадать в браузер.

1. В Mapbox Account → Tokens создайте отдельный public token.
2. Дайте ему минимальные права: `styles:tiles` (при необходимости
   `styles:read`). Не давайте лишних scope.
3. По возможности ограничьте токен URL-ами, с которых открывается панель:
   `http://127.0.0.1:5001/*`, `http://localhost:5001/*`, адрес планшета/домена.
   Для локальной проверки по LAN-IP может потребоваться шаблон вида
   `http://192.168.*/*`; если Mapbox не принимает приватный шаблон, используйте
   временный токен без URL-ограничения и ротируйте его после проверки.
4. Создайте файл (токен не попадёт в историю shell, если вводить его в stdin):

```bash
cd /root/taxi-mapbox-01
umask 077
cat > static/mapbox-token.json
```

Вставьте JSON и нажмите Ctrl-D:

```json
{"accessToken": "pk.ВАШ_ПУБЛИЧНЫЙ_ТОКЕН"}
```

5. Проверьте формат, не выводя токен целиком:

```bash
python3 - <<'PY'
import json
token = json.load(open('static/mapbox-token.json'))['accessToken']
print('prefix:', token[:3], 'length:', len(token), 'is_public:', token.startswith('pk.'))
PY
```

Ожидается `prefix: pk. is_public: True`.

6. Убедитесь, что файл игнорируется Git:

```bash
git check-ignore -v static/mapbox-token.json
```

Файл должен быть в списке ignored. **Не добавляйте его в Git, отчёты и логи.**

## Проверка в браузере

1. Откройте панель, обновите страницу с очисткой кэша (Ctrl+Shift+R).
2. DevTools → Network → фильтр `api.mapbox.com`. Должны быть запросы
   `/styles/v1/mapbox/streets-v12/tiles/512/...` со статусом 200.
3. В правом нижнем углу карты атрибуция должна содержать Mapbox и
   OpenStreetMap.
4. Убедитесь, что в запросах нет `sk.`.
5. Удалите/переименуйте `static/mapbox-token.json` и обновите страницу:
   карта должна остаться рабочей на OSM, атрибуция — OpenStreetMap.
6. Верните файл. Проверьте масштаб (кнопки +/−), режим «За рулём», маршрут,
   GPS-точку и отсутствие ошибок в консоли.

Если токен есть, но Mapbox не ответил, в консоли будет общее предупреждение
без значения токена, а карта останется на OSM.

## Проверка на планшете Android Chrome

Production Flask на порту 5000 не останавливать. Для STAGE-A поднимается
изолированная копия на другом порту.

1. Запустите изолированную панель на порту 5001. Скрипт создаёт временное
   хранилище с пустым искусственным состоянием и не читает production JSON:

```bash
cd /root/taxi-mapbox-01
HOST=0.0.0.0 PORT=5001 .venv/bin/python tests/serve_isolated.py
```

Данные живут во временном каталоге и очищаются после остановки процесса.

2. С планшета в той же сети откройте `http://<IP-сервера>:5001`.
   Для проверки карты этого достаточно.

3. Для GPS нужен secure context. Подключите планшет по USB, включите отладку
   и выполните на сервере:

```bash
adb reverse tcp:5001 tcp:5001
```

На планшете откройте `http://localhost:5001` — Chrome считает localhost
secure context, геолокация разрешается.

4. Чек-лист на устройстве:
   - карта загрузилась, атрибуция Mapbox + OpenStreetMap;
   - кнопки +/− меняют масштаб, карта не «съезжает»;
   - «Режим за рулём» разворачивает карту на весь экран, кнопка «Выйти»
     возвращает панель;
   - «Начать отслеживание» запрашивает геолокацию и ставит синюю точку;
   - после 2–3 точек появляется линия маршрута и зелёный маркер старта;
   - остановка отслеживания убирает круг точности;
   - нет красных ошибок в Chrome DevTools;
   - в запросах нет `sk.`.

## Откат

Откат не требует изменений БД, миграций или перезапуска Flask.

1. Быстрый откат карты на OSM без изменения кода: удалить/переименовать
   `static/mapbox-token.json` и обновить страницу.
2. Полный откат кода: вернуть `static/script.js` из
   `artifacts/rollback/script.js.original` (SHA-256
   `3571c6396d1c42091094744a7df11eb11298c55834054bbc2e0406b4a0f94cc6`),
   обновить страницу. `app.py`, `storage.py`, JSON и база не затрагиваются.
3. Удалить `static/mapbox-token.json`, если он больше не нужен.
