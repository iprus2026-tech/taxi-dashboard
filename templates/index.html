Как включить геолокацию

Если окно с запросом не появилось или доступ уже запрещён:

  • Chrome / Android: значок замка или ⓘ рядом с адресом → «Разрешения» → «Геолокация» → «Разрешить», затем обновите страницу.
  • Safari / iPad: «аА» в адресной строке → «Настройки для сайта» → «Геолокация» → «Разрешить».

Геолокация работает только по HTTPS или на localhost. Если приложение открыто по локальному IP (http://192.168…), браузер заблокирует GPS — запускайте его на самом планшете по http://127.0.0.1:5000 либо используйте HTTPS.

Для точности включите GPS и держите планшет с прямым обзором неба. Первые 50–100 метров могут быть неточными. Если статус долго показывает «ждём улучшения сигнала», выйдите на открытое место.
