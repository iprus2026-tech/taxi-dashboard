**Рабочий дашборд таксиста для Android / Termux**

Локальное веб-приложение для планшета или телефона: карта, автоматический
GPS-пробег, деньги, история смен, погода и режим за рулем. Запускается прямо
на устройстве, данные хранятся рядом с приложением — без облака и API-ключей.

## ✨ Возможности

| | |
|---|---|
| 🗺️ **Карта** | Leaflet + OpenStreetMap, центр на Москве, линия маршрута и текущее положение |
| 📍 **GPS-пробег** | `navigator.geolocation.watchPosition`, точка сохраняется каждые ~75 м, чтобы не нагружать сервер |
| 💤 **Экран не гаснет** | Screen Wake Lock включается вместе с трекингом и отпускается при остановке |
| 💰 **Деньги** | «+ Заказ» и «+ Расход» с категориями (Бензин, Мойка, Еда, Штраф) и крупный счетчик чистой прибыли |
| 🕘 **История** | Карточки завершенных смен: дата, время в пути, км, выручка, расходы, прибыль и журнал операций |
| 🌦️ **Погода** | Open-Meteo без ключа: температура, описание, ветер; синяя подсветка при дожде или снеге |
| 🚗 **Режим за рулем** | Полноэкранная карта и три огромные кнопки статуса — ничего лишнего |
| 🌙 **Темная тема** | Крупные элементы под палец, адаптив под планшет и телефон |

## 🖥️ Интерфейс

Приложение состоит из нескольких экранов и панелей:

- **Шапка** — логотип, виджет погоды в Москве (иконка, температура, описание,
  ветер), кнопка «История» и текущий статус. При осадках погода подсвечивается
  синим — удобный сигнал о возможном повышенном спросе.
- **Карта** — интерактивная карта Leaflet/OpenStreetMap. На ней отображаются
  маршрут, стартовая точка и текущее положение с кругом точности GPS.
- **Профиль авто** — марка и госномер, сохраняются на сервере.
- **Пробег** — общий километраж за смену, последний отрезок, количество точек,
  запуск/остановка GPS-трекинга и сброс пробега.
- **Деньги** — выручка, расходы и чистая прибыль; заказы и расходы добавляются
  в пару нажатий.
- **История** — отдельный экран с карточками прошлых смен и раскрывающимся
  журналом операций. Возврат — кнопкой «Вернуться к текущей смене» или `Esc`.
- **Режим за рулем** — по нажатию кнопки на карте остаются только карта на весь
  экран и три крупные кнопки внизу: «Свободен», «На заказе», «Не на линии».
  Выход — «Выйти» или `Esc`.

> 💡 На телефоне шапка аккуратно переносится: бренд, история и статус остаются
> сверху, погода занимает отдельную широкую строку.

## 🚀 Установка и запуск

### Android / Termux

```bash
pkg update
pkg install python git

git clone https://github.com/iprus2026-tech/taxi-dashboard.git
cd taxi-dashboard

python3 -m venv .venv
source .venv/bin/activate
pip install flask

python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

### Linux / macOS

```bash
git clone https://github.com/iprus2026-tech/taxi-dashboard.git
cd taxi-dashboard

python3 -m venv .venv
source .venv/bin/activate
pip install flask

python app.py
```

> На Debian/Ubuntu для `venv` может понадобиться пакет:
> `sudo apt install python3-venv`.

### Если виртуальное окружение недоступно

Можно установить Flask в текущее окружение и запустить приложение напрямую:

```bash
pip install flask
python app.py
```

## 📱 Как пользоваться

1. **Профиль авто** — введите марку и госномер, нажмите «Сохранить».
2. **Отслеживание** — нажмите «Начать отслеживание» и разрешите браузеру
   доступ к геолокации. Маршрут и пробег будут обновляться автоматически.
3. **Статус** — выберите «Свободен», «На заказе» или «Не на линии».
4. **Деньги** — добавляйте заказы и расходы; чистая прибыль считается сразу.
5. **Погода** — обновляется при загрузке и каждые 15 минут; дождь и снег
   подсвечиваются синим.
6. **Режим за рулем** — нажмите кнопку на карте, чтобы убрать все панели
   и оставить только карту и крупные кнопки статуса.
7. **Завершить смену** — итоги сохранятся в `shift_history.json`, а карта,
   пробег и деньги очистятся для новой смены.

## 🔌 API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/` | Главная страница |
| `GET` | `/api/state` | Текущее состояние: авто, статус, смена |
| `POST` | `/api/car` | Сохранить марку и госномер |
| `POST` | `/api/status` | Сменить статус водителя |
| `POST` | `/api/track` | Добавить точку GPS-трека |
| `POST` | `/api/mileage/reset` | Сбросить маршрут и пробег |
| `POST` | `/api/orders` | Добавить заказ |
| `POST` | `/api/expenses` | Добавить расход |
| `POST` | `/api/shift/finish` | Завершить смену и сохранить итоги |
| `GET` | `/api/history` | История завершённых смен |

## ⚠️ Важные ограничения

- **GPS и Wake Lock работают только в защищённом контексте** — по `https://`
  или на `localhost`/`127.0.0.1`. Если открыть приложение по локальному IP
  (`http://192.168…`), браузер заблокирует геолокацию. Запускайте приложение
  на самом планшете или используйте HTTPS.
- **Нужен интернет** для тайлов карты и погоды. Без сети интерфейс продолжает
  работать, но карта и виджет погоды могут быть недоступны.
- **Один водитель и одно устройство** — данные хранятся в локальных JSON-файлах,
  без базы данных и многопользовательского режима.
- Браузер может сам снять Wake Lock при переключении вкладки; при возврате
  приложение запросит блокировку снова, если трекинг ещё активен.

## 🩺 Если что-то не работает

| Проблема | Что делать |
|---|---|
| Браузер не спрашивает геолокацию | Разрешите доступ в настройках сайта: замок/ⓘ у адреса → «Разрешения» → «Геолокация» |
| «Геолокация недоступна» | Проверьте, что открыто по `https://` или `127.0.0.1`, и включён GPS |
| Экран гаснет | Браузер не поддерживает Screen Wake Lock — обновите Chrome/Safari |
| Карта пустая | Нет доступа к тайлам OpenStreetMap — проверьте интернет |
| Порт 5000 занят | Запустите на другом порту: `python app.py` → измените `port` в `app.py` |
| Пропала история | `shift_history.json` создаётся только после «Завершить смену» |
